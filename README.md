Atividade de react (pam) utilizando bibliotecas e permissões para testar uso de componentes do Android

Para rodar o projeto
Voce primeiro deve clonar os arquivos do projeto ou baixa-los
"git clone https://github.com/Davi-levy/react-permissoes/"

Segundo, instale todos os requisitos e modulos do projeto com "npm install"
Depois instale o EXPO "npm install expo"
Depois basta rodar o projeto com "npx expo start"

Lembrando que, os comandos precisam ser usados no mesmo local e terminal onde os arquivos do projeto ja estão.
